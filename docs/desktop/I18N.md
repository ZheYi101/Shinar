# 桌面国际化入口

2026-10-29。本版本交付中文界面，并为后续多语言保留 Qt 标准入口。

## 显示语言和学习母语

- `DesktopPreferences.displayLanguage` 独立保存，默认 `zh_CN`；外观设置提供中文与跟随系统。当前只有中文资源，非中文系统仍回退中文。
- `DesktopLanguageController` 读取 `QLocale.system().uiLanguages()` 的优先顺序，解析可用资源并管理 `QTranslator`、`QQmlEngine.retranslate()`。不调用模型、不改变活动线程、不清理音频、不重建学习历史。
- `nativeLanguage` 仍是语言学习领域字段，影响新会话的学习 profile。改变显示语言不改变它，也不改既有会话的冻结 profile。
- `suggested_native_language()` 提供系统语言到领域枚举的首次建议映射。当前保持中文默认；后续启用系统默认时，仅对尚无显式偏好的首次用户应用建议，并允许分别修改显示语言与学习母语。
- 材料原文、用户消息、模型回复、原确认引文与设备名称属于内容，不能送入界面翻译函数。模型输出语言继续由学习 profile 决定。

## 文案和资源

QML 固定文案使用 `qsTr("中文源文案")`；包含数据时使用完整句子，例如 `qsTr("%1 秒").arg(seconds)`。Python 桌面提示使用 `QCoreApplication.translate("Desktop", "中文源文案")`，参数使用命名格式占位符；不使用翻译整段插值结果的做法。领域代码继续不依赖 Qt。

翻译源文件为 `src/shinar/desktop/translations/shinar_zh_CN.ts`，由 Qt Linguist 工具从 QML 和桌面 Python 提取。中文直接使用源文案，不需加载 QM。运行：

```powershell
.venv\Scripts\python.exe scripts\update_translations.py
```

新增语言时增加对应 TS、完成翻译并用 `pyside6-lrelease` 生成 QM，再加入 `AVAILABLE_LOCALES`、显示语言偏好选项及设置的语言名。QM 与 TS 均由 wheel 资源规则分发，安装包检查覆盖它们。提取脚本当前只开放已交付的中文，扩展时同步加入新 locale。占位符和文案语义变化时重新提取，不手改生成目录来掩盖源代码缺失。

当前 Qt 翻译标记覆盖桌面控件、可访问名称及桌面层固定提示。已有业务层异常、provider 状态与本地语音目录的说明仍按原业务返回中文；后续增加完整语言包前，应将这些边界改为稳定错误／状态代码和参数，在桌面适配层映射翻译，不能把技术标识、用户数据或模型内容当作源文案提取。已有分类同义词属于内容匹配规则，也不随显示语言翻译。

验证包括系统语言优先顺序、未知语言回退、偏好重启恢复，以及真实 QML／Python 文案使用测试翻译器后改变，而原文、线程、草稿和音频保持完整。当前不宣称已交付英语或日语界面。

接口依据：[Qt 翻译源代码约定](https://doc.qt.io/qt-6/i18n-source-translation.html)。项目仍固定 PySide6 6.11.1，未因文档站当前版本而升级依赖。
