## 本机发现与修复

### 受管 Python 字节码导致重复安装

旧资源收据将 Python 运行时会更新的 `.pyc` 等字节码当作不可变文件。正常导入会使其大小或内容变化，导致已安装资源被误判失效，并在后续环境准备中重复安装、产生隔离副本。

提交 `7f5f41d` 让受管 Python 资源的新收据排除可再生成字节码，旧收据读取与校验采用相同兼容规则。源代码、动态库及其他模型文件继续严格校验，明示必需文件不豁免。迁移仅排除可确认所有者、修订版本和 UUID 的隔离副本，将其具体源位置列为保留项；未知内容不按名称批量排除或删除。

### Melo 准备期间出现隐式 NLTK 联网

`g2p_en` 导入时检查词典 ZIP，而旧准备流程只保留了解压目录。即使本地已有词典，仍会尝试下载；旧 C 盘环境的一次实际计算虽通过，但耗时 67.2 秒，并记录了下载被阻断的错误。

提交 `31e3c1b` 保留词典 ZIP 并继续解压，准备探针与正常推理共用独立的离线检查：限定本环境的数据路径、拒绝 NLTK 下载、缺件时立即报告明确错误，不回退到个人缓存，也不放宽超时预算。旧环境缺件时标记需要修复，迁移继续重建已确认可修复的 Melo 环境；损坏标记不能冒充可修复状态。
