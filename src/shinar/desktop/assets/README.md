# Shinar 应用图标

`app-icon.svg` 是本项目绘制的几何图标：暖纸色的巴别塔轮廓，搭配现有灰绿主色。2026-11-08 随 Shinar 定名更新，替代旧的双对话气泡。
它用于 Windows 程序、任务栏、快捷方式和卸载入口，与页面内功能图标分开维护。

## 出处与图形解释

- 名称出自《创世记》11:2 的地名 Shinar（示拿），巴别塔故事的发生地域，详见[项目命名记录](../../../../docs/product/NAMING.md)。
- 图形以逐层收窄的圆塔、斜向上升的环绕回廊、拱形开口和未完成的塔顶建立巴别塔联想。视觉参考为老彼得·勃鲁盖尔的巴别塔绘画传统；出处见[维也纳艺术史博物馆专题](https://bruegel.at/en/the-tower-of-babel/)和[博伊曼斯博物馆藏品页](https://www.boijmans.nl/en/collection/artworks/3723/the-tower-of-babel)。
- 塔基右侧收成对话气泡的尾部，连接语言交流与项目的输出练习主线。这是本项目的图形解读。
- 经文提供地名与故事出处，绘画提供视觉联想；图标的具体建筑轮廓属于现代几何设计，不作为示拿地区真实建筑的复原。

使用两种纯色：灰绿 `#56634F` 与暖纸 `#F7F3E9`。不使用字母、细砖纹、阴影或渐变；小尺寸优先保留塔形与回廊。此处说明的是项目自行绘制的 SVG，没有嵌入、描摹或打包馆藏照片。

## 导出

SVG 为母版。用 `scripts/generate_app_icon.py` 通过 Qt SVG 渲染生成 512px PNG 和含
16、20、24、32、40、48、64、128、256px 的 ICO；无需外部绘图库或模型服务。
本文件不改变项目整体许可证，亦不包含第三方图形素材。
