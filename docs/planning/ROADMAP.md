## 独立工作与后续语音

- [本地语音严格评测](../validation/speech/LOCAL_SPEECH_STRICT_EVALUATION_2026-10-28.md)已完成客观阶段；[用户筛选与试听](../validation/speech/LOCAL_SPEECH_SELECTION_2026-10-29.md)按平均首字 ≤500ms 保留 SenseVoice 中/英四项，后续仅剩余候选进入 GPU 队列，日语 STT 暂缺。TTS 中文 Melo、英语 Lessac、日语 VOICEVOX 为当前候选；Kokoro/Qwen 退出本轮，Amy 有用户确认的否定词错误，修复前仅备选。允许按语言安装不同模型；真实端点到首字、常驻预热、播放连续性和完整链路未验收。
- [读后对照聊天功能设计](../product/CONVERSATION_WORKSPACE_DESIGN.md)的核心交互已由用户认可，组件、状态与验收规则供总 UI 设计参考；应用增量尚未排期，不纳入本轮 AI 预处理设计的实现范围。设计认可和交互原型不等于已交付。
- 后续连续语音仍采用 LiveKit 方向：分别验证本机 RTC、连续音轨与打断，再接入实际流式 STT/TTS。Mock、计算测速和文本通过都不能替代真人设备验收。
