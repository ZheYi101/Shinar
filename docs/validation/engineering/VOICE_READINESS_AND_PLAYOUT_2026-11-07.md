# 对话页预检查与连贯朗读

日期：2026-11-07。对应用户关于进入对话页预检查及逐句朗读停顿的反馈。保留工作树已有阅读器、视觉、模型目录与分发改动；不修改个人选择，不调用付费模型。

## 交付行为

- 独立检查麦克风、会话语言的 STT/TTS 与已准备的 RTC 组件。本地模型沿用冻结 profile 和资源准入；远程只显示配置状态。缺资源显式前往设置，无自动下载。
- 设备诊断在授权后最多采集 1.5 秒，收到帧立即关闭，音频丢弃，不转写、提交或保存。持续监听仍须点击开始。页面离开、线程变化、权限迟到和退出不能重开采集。
- 准备不占业务锁，草稿继续可编辑；消息／主题通知不重复预热。设置变更失效，在用语音保持冻结。空闲释放不被轮询保活。
- 合成与交付独立运行；首句优先，后续合并已到达的完整句子。已完成波形含交付中一段限制 3 段／24 MiB，构造中单段另限 24 MiB。停止、插话与关闭取消预取和旧代际输出，不额外调用 LLM。
- 保守处理边界近数字静音，保留 20/80 ms 余量，不改变内部停顿、采样率、语速和历史。真实模型此次没有可安全裁剪的静音，移除量如实为零。

## 复现与限制

```powershell
$env:RUN_REAL_AI_TESTS='0'
$env:QT_QPA_PLATFORM='windows'
.venv\Scripts\python.exe scripts/validate_voice_readiness.py
# 显式使用已有缓存，真实 RTC/播放及短暂丢弃式麦克风诊断：
.venv\Scripts\python.exe scripts/validate_voice_readiness.py --speech-cache <普通设置缓存> --runtime-root <已准备组件> --microphone --compare-serial
```

缩放另进程设置 `QT_SCALE_FACTOR=1.25` 或 `1.5`，不改系统设置。脚本仅使用独立库，不读 `.env`，不请求付费模型，不借用开发 DLL 或注入准备 profile。

收到 PCM 不证明人声识别、降噪、耳机／扬声器听感或 AEC。真人连续对话、扬声器 20 段防自触发、10 次插话及设备移除恢复仍按原门禁单列。本次不保证所有 TTS、CPU/GPU 和长回复都无停顿。
