# 自由聊天、轻量准备与部分阅读验证（2026-10-28）

## 产品决定

大量选题卡让软件像课程入口，前置话题和模拟回答成本过高。默认主线改为：导入保存 → 确认已读范围 → 自由开聊 → 按真实兴趣补充少量参考和方向 → 轻量复盘。保留既有付费全书资料和历史，它们不再是开聊门槛。

沿用 Python/Pydantic、SQLite/WAL、长期 asyncio worker、PySide6/QML MD3 和独立推理/对话角色，没有新增向量数据库、模型服务或编排框架。取舍见 Decision 0018（原重复编号 0015 已更正）。

本报告保留当时零模型初始索引的实际结果。后续拟补充基础语义理解，见[专项设计](../../architecture/ai/PREPARATION_AND_DIALOGUE.md)；该设计尚未实施，不回写本报告的历史指标。

## 当前实现

- 桌面导入只保存原文与规范化文本；确认已读范围后，按位置、哈希和词项建立约 1800 字符的小段索引。默认不调用模型生成题库或整书汇总。
- 优先粘贴已读的最后一句精确定位。百分比只作辅助，向前取整并主动预览末尾、核对后确认，不代表 EPUB 章节或阅读器页码。
- 新会话默认 topic=None，使用目标语言短开场，无需模型。初始想法只进入草稿；roleplay 仍需主动选择。
- 前台只走对话角色，结合当前发言和最近两条历史，最多选三段、每段至多 1200 字符。索引关注人物、引文、正文/后记标题提示和跨人物覆盖，不默认发送全书所有段落概要与可能回答。
- 至少两次真实发言后，相关来源变化才后台整理微型参考。自由会话最多三次尝试，失败/取消也计数，跨重启保留；结构无效不自动重试。单次最多 4000 tokens，DeepSeek 用 low effort。
- 方向建议最多三个，可忽略，点击仅填草稿。提示放在消息滚动区，不挤动输入框和发送按钮。Prompt 接续异议与改口，减少评价学习者、连续追问，要求承认自己的错误；截断流不能作为完整回复保存。
- 已读末尾冻结于会话 options，模型路径与已读原文视图都裁剪后文。部分阅读不使用旧全书概要、全局人物/话题，只复用完全位于已读范围的分段资料。旧付费全书缓存另存，切回读完可恢复。
- 自由会话复盘依据真实输出，不重复全书分析，输出有预算，允许零纠错、零复习项。

旧 provider 显式话题 API 保留兼容，新的默认桌面入口不调用其批量题库操作。

## 实机与实际服务

通过可见 Windows 窗口的文件选择器重新导入用户提供的完整 Lolita EPUB（681437 字符），没有直接向数据库注入历史。用原文末句确认读到规范化字符 196682（28.86%），得到 129 段已读索引。导入、索引和自由开场均为零模型调用。

当前本地推理与对话角色均为 deepseek-flash，独立思考配置保留。六轮实际交流涵盖 Charlotte 的学校计划、叙述者对读者同情的影响、反驳 AI 的概括、改变关注点、自然收尾和后文传闻边界。最后一轮明确要求不确认后文，AI 没有确认或否认，保持在已读场景。

早三轮仍出现机械夸赞、追问和过度概括。根据实际输出调整系统指令与逐轮提醒，重启恢复同一线程后继续测试，后续减少了连续追问。小样本不能证明语气问题已完全解决。

实际共 6 次前台回复、3 次后台参考、1 次结束复盘。前台平均 1909 输入 token。全部请求合计 16790 输入 / 3392 输出 token，含后台思考输出；没有重做全书摘要或生成题库。后台与复盘请求实际覆盖为 4000 token 上限。复盘成功，纠错及复习项均为空，完成线程有 13 条真实消息。活动线程和完成线程均经过进程重启恢复。

## 验证和本地资料

- 离线：244 passed / 1 skipped，64.71 秒，Ruff 通过。覆盖零模型导入、自由开场、旧数据、部分阅读隔离、范围缓存、后台失败预算与重启、截断流、QML 实际点击、建议只填草稿及发送位置稳定。
- 桌面：显式加载字体，可见窗口检查 360/600/800/1180/1440px 材料页及明暗主题，检查真实完成历史与复盘。离屏和可见窗口证据分别保存。
- 包：wheel 隔离启动通过，41 项 QML/图标/许可及目录资源检查通过，reading_scope/source_index 模块随包分发。
- 私有资料在忽略目录 build/free-chat-validation：real-library/lingualoop.sqlite3、reference-index.json、actual-free-chat.md、real-free-chat-summary.json，以及 real-ui/、final-ui/。
- 六轮新例子使用隔离库，默认个人库中的整书资料、三个实际历史及复盘继续保留。用 LINGUALOOP_DATA_DIR 指向本次库即可查看新例子。

原文、逐字会话和模型调用元数据不提交仓库，公开文档只保留汇总。本轮没有新增 STT/TTS 调用，不宣称连续语音通过。

## 继续优化的依据

优先比较引用相关性、事实归属、异议承接、背景参考的实际增益、token 和完整延迟。有增益证据后才增加局部事实压缩或语义召回，不恢复无上限预写回答。章节定位、跨会话参考复用、金额预估、模型固有知识的防剧透验证和真人连续语音仍待完成。

## 主要代码位置

- `core/reading_scope.py`：已读前缀与旧缓存隔离。
- `application/source_index.py`、`core/material_context.py`：本地索引、人物/引文选择和有界参考包。
- `application/learning_workbench.py`、`kernel/session_runner.py`：自由会话、阅读范围快照、持久化后台预算。
- `providers/openai_compatible.py`：聊天/参考/复盘 Prompt、有限预算与截断流错误。
- `desktop/viewmodel.py`、`MaterialsPage.qml`、`ConversationPage.qml`：阅读位置、直接开聊、可选方向和草稿交互。

交付时已用普通桌面入口打开本次隔离验证库，显示六轮实际记录。它通过进程级 LINGUALOOP_DATA_DIR 指定，不修改系统环境；退出后常规启动仍读取原个人库。
