## 已完成的更换

## 保留的问题与边界

- 独立小样阶段曾得到离屏渲染图，但正式 ApplicationWindow 的 WebEngine 在本机离屏抓图可能空白。因此本轮阅读区视觉证据使用原生 Windows 窗口，不能拿 DOM 非空代替画面可见。
- 可见窗口检查发现 WebEngine 纹理可能越出原文区，已在阅读区和视图设置裁剪；修正后的图中聊天区正常。连续强制抓图还曾触发 D3D／Chromium 共享纹理错误；检查器改为在布局变化后抓图，不将这种压力抓图当作正常使用或长期 GPU 稳定性验收。
- 查找防抖采用主线程 Qt 定时器，不依赖 QML 动画时钟；查询在执行前复核文档身份，离开页面后不执行旧查询。可见脚本由 Qt 定时器推进异步步骤，操作之间让出主事件循环，在 StackLayout／分栏变化后完成控件布局，避免从隐藏页面或零尺寸控件得出通过结论。仅在临时测试偏好中关闭动画，查找弹层也验证 Escape 实际关闭；未修改用户偏好或生产渲染参数。
- 本轮未使用用户实际小说，也未测试真实 AI 对话质量。固定版式、出版者 CSS、SVG 插图、未索引外置注释页和整本无缝连续滚动不在本次实现范围。
- Windows 私有 Python 分发仍带完整 PySide6；分发探针已增加 QtWebEngineProcess、Chromium／ICU／locales、QtWebEngine／QtWebChannel 模块检查。本轮未重建整个 ZIP／安装器，不将源码 wheel 检查等同于安装器迁移通过。
