# 语音容量与准备进度规范化

日期：2026-11-07。针对用户反馈的本地模型列表和音频设备准备区域，兼顾计算与加速页。仅增量修改容量投影、只读文件统计和准备状态接线；未重启正在使用的应用，未修改个人配置、学习数据、模型选择或安装策略。

## 变化

- 三处统一为「模型下载文件」「预计下载」「安装需可用空间」；明确共享环境、安装临时文件及安全余量，按 MiB／GiB 显示，不能当作最终磁盘占用或运行内存。
- 模型库与连续语音分别统计各自缓存根目录，显示总文件大小、已安装资源、下载与安装缓存、其他。只读统计位于后台；不跟随外部链接，硬链接只计一次并优先归入已安装资源；数字为逻辑文件大小的快照，不是 NTFS 扇区分配量，不包含软件安装目录和学习资料。
- 单模型详情区分安装文件、保留缓存、运行内存实测、内存准入预算及显存估算。共享环境不重复分摊；缺少内存记录时不显示为 0 MiB；旧测量摘要中的重复内存字段移至独立说明。
- 连续语音准备传递运行环境、Silero VAD、LiveKit 阶段及当前文件身份，安装／验证阶段使用不定进度；文件达到 100% 不显示整项完成。停止后的过期事件被原操作身份拒绝，准备期间不开麦。
- 模型库详细口径通过「空间说明」展开，保留窄窗口的列表空间；新增文案进入 Qt 翻译源。统计和大小计划不在音频帧回调中执行，容量属性共用一次计划结果。
